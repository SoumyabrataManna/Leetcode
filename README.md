# LeetCode Workspace

A structured workspace for solving LeetCode problems and tracking progress.

## Directory Structure

```
.
├── problems/
│   ├── python/
│   │   ├── easy/
│   │   ├── medium/
│   │   └── hard/
│   ├── javascript/
│   │   ├── easy/
│   │   ├── medium/
│   │   └── hard/
│   ├── cpp/
│   │   ├── easy/
│   │   ├── medium/
│   │   └── hard/
│   ├── java/
│   │   ├── easy/
│   │   ├── medium/
│   │   └── hard/
│   └── go/
│       ├── easy/
│       ├── medium/
│       └── hard/
├── templates/      # Template files for different languages
└── notes/          # Study notes, patterns, and algorithms
```

## Naming Convention

For problem files, use the format: `{problem-number}-{problem-name}.{ext}`

Example:
- `problems/python/easy/1-two-sum.py`
- `problems/javascript/medium/2-add-two-numbers.js`
- `problems/cpp/hard/3-longest-substring.cpp`

## Supported Languages

- Python (.py)
- JavaScript/TypeScript (.js/.ts)
- Java (.java)
- C++ (.cpp)
- Go (.go)

## Problem Template

Each problem solution should include:
1. Problem link and description
2. Approach/Algorithm explanation
3. Time and Space complexity
4. Solution code
5. Test cases

## Progress Tracking

| Difficulty | Solved | Total |
|------------|--------|-------|
| Easy       | 1      | 1-    |
| Medium     | 0      | -     |
| Hard       | 0      | -     |
